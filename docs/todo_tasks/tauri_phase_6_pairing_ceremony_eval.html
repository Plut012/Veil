Design Decisions

DecisionRationale
create_qr_payload returns Result instead of bare tuple QR generation and PNG encoding are fallible. Using unwrap() in library code violates project rules. PairingError::QrGeneration and PairingError::Internal variants cover these paths.
HandshakeJson uses #[serde(rename = "type")] type is a reserved keyword in Rust. #[serde(rename = "type")] is cleaner than the raw identifier r#type inside the struct body and avoids visual noise throughout the code.
Public HandshakeData struct vs. returning HandshakeJson Internal serde structs should stay private. HandshakeData exposes only the meaningful fields (name, env) without leaking the internal type field to callers.
parse_handshake_message returns Option, not Result As specified: any failure (wrong key, bad base64, wrong type, malformed JSON) is treated identically from the caller's perspective — the message is not a valid handshake. Option cleanly communicates this without exposing error variants the caller cannot act on differently.
URL_SAFE base64 throughout Consistent with crypto/keys.rs and the Python implementation. Safe for transmission in Telegram messages without escaping.
