Implementation Details

engine.rs — Sealed Format

secretbox::seal() returns ciphertext+MAC with no nonce. The nonce is generated fresh per call via secretbox::gen_nonce() and prepended manually. secretbox::open() receives only the ciphertext+MAC slice (bytes 24..end).

Error Handling

No unwrap() in library code. CryptoError and KeyError both use thiserror::Error. The only expect() calls are on invariants that the type system guarantees (e.g., constructing a secretbox::Key from a &[u8; 32] — that slice length is enforced by the type).

sodiumoxide::init()

Called in every test's init() helper. Safe to call multiple times. Should also be called at app startup (in main()) before any crypto operations are performed in production.
