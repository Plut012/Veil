Veil — Phase 7 Frontend Evaluation COMPLETE

SvelteKit app implementing the messaging UI over WebSocket. Built 2026-05-24.

Acceptance Criteria

  • ✓
    SvelteKit project initializes and builds
    npm run build → dist/ via adapter-static. Zero errors.
  • ✓
    WebSocket connects to backend on page load
    VeilSocket.connect() called in +page.svelte onMount. URL: ws://127.0.0.1:8900/ws
  • ✓
    Auto-reconnect on WebSocket disconnect
    Exponential backoff: 1s, 2s, 4s, 8s, 16s, 30s (max). Restarts on unexpected close.
  • ✓
    Contact list renders from backend state
    Backend sends { type: "contacts" } on connect. setContacts() updates the Svelte store. ContactList renders reactively.
  • ✓
    Selecting a contact shows conversation view
    selectedContactId store drives ChatView. Shows contact name in header, message list, compose area.
  • ✓
    Typing and sending a message works end-to-end
    Compose sends on Enter (Shift+Enter = newline). Calls veilSocket.sendMessage(). Backend echoes direction: "out".
  • ✓
    Incoming messages appear in real-time
    WS handler dispatches { type: "message", direction: "in" } → addMessage() → MessageList re-renders. Auto-scrolls to bottom.
  • ✓
    Pairing modal — initiator flow shows QR code
    Sends { type: "initiate_pairing" }. Backend returns pairing_qr with base64 PNG. Displayed in PairingModal. Labeled ephemeral.
  • ✓
    Pairing modal — joiner flow activates camera and scans QR
    html5-qrcode library dynamically imported. Camera activated on "Scan QR" selection. On decode: completePairing(qrData) sent.
  • ✓
    New contacts appear in sidebar after pairing
    pairing_complete handler calls addContact(). Modal auto-closes after 1.2s delay.
  • ✓
    Settings panel allows envelope template editing
    EnvelopeConfig component. User edits template, clicks apply → updateEnvelope(template) sent. Placeholder: {ciphertext}.
  • ✓
    Theme CSS variables produce warm, muted, art nouveau aesthetic
    16 CSS variables defined in app.css. Theme overrides in themes/art-nouveau/theme.css. Loaded dynamically via link tag in layout.
  • ✓
    No tooltips, no onboarding, no hand-holding
    Interface communicates through form. Contact list shows indicator dots. Compose placeholder is "write...". Pair button is "+ pair".
  • ✓
    Frontend never touches crypto or Telegram directly
    All operations go through VeilSocket → backend. No key material, no Telegram imports anywhere in frontend.

WebSocket Protocol Coverage

Client → Server                          Implemented in
─────────────────────────────────────────────────────────
{ type: "send_message", ... }            Compose.svelte → veilSocket.sendMessage()
{ type: "list_contacts" }                veilSocket.requestContacts()
{ type: "initiate_pairing" }             PairingModal.svelte → veilSocket.initiatePairing()
{ type: "complete_pairing", qr_data }    PairingModal.svelte → veilSocket.completePairing()
{ type: "update_envelope", template }    EnvelopeConfig.svelte → veilSocket.updateEnvelope()
{ type: "set_theme", theme_id }          SettingsPanel.svelte → veilSocket.setTheme()

Server → Client                          Handled in
─────────────────────────────────────────────────────────
{ type: "connected" }                    connectionState.set("connected")
{ type: "contacts", contacts: [...] }    setContacts() → contacts store
{ type: "message", direction, text }     addMessage() → messages store
{ type: "pairing_qr", qr_image }         PairingModal on() handler → qrImage display
{ type: "pairing_complete", contact }    addContact() + modal close
{ type: "error", message }               console.error (non-fatal)

Design Decisions

  • →
    Static adapter (not Node adapter)
    Backend serves frontend/dist as static files. SvelteKit SSR is disabled. This matches the existing FastAPI StaticFiles mount in server.py.
  • →
    html5-qrcode lazy import
    Dynamically imported inside mountScanner() to avoid SSR issues (it accesses window). Fails gracefully with a user-visible error if camera permission denied.
  • →
    Theme CSS in static/ (not dynamic fetch from repo root)
    themes/art-nouveau/theme.css is copied to frontend/static/themes/ so it gets included in the dist build and served at /themes/art-nouveau/theme.css.
  • →
    Svelte 5 with legacy stores
    Uses svelte/store writables (Svelte 4 API, fully supported in Svelte 5). Keeps code simple and readable.

How to Run

# Start the backend (from veil/ root):
uv run python -m veil

# In a separate terminal, start frontend dev server:
cd frontend
npm run dev
# → http://localhost:5173

# Or build for production (served by FastAPI):
npm run build
# → frontend/dist/ served by FastAPI at http://localhost:8900
