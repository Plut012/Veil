Architecture Notes

  • The bridge owns Arc<SqliteSession> and Client (cloneable handle) as part of ConnectedState created on connect().
  • The SenderPoolRunner runs as an independent tokio::spawn task driving all network I/O. The Client is just a cheap cloneable handle to it.
  • The update listener task owns the UpdateStream (which wraps the updates receiver from SenderPool). It cannot be shared — this is by design in grammers 0.9.
  • Peer resolution for send() uses the session cache populated during auth and by stream_updates. Peers not in cache will use ambient authority (access_hash=0), which works for contacts.
  • create_channel uses the raw tl::functions::messages::CreateChat TL function since grammers 0.9 has no high-level API for group creation.
