Files Created

File Description
src/veil/crypto/engine.py encrypt(plaintext, key) -> bytes and decrypt(sealed, key) -> bytes. Delegates entirely to PyNaCl SecretBox — random nonce generated per call, auth tag verified on decrypt. CryptoError propagates to caller.
src/veil/crypto/keys.py generate_key() — 32 random bytes via nacl.utils.random. key_to_base64() / key_from_base64() — URL-safe base64 with length validation on decode.
src/veil/crypto/__init__.py Re-exports all five public symbols: encrypt, decrypt, generate_key, key_to_base64, key_from_base64.
tests/test_crypto.py 14 tests across three classes: TestEncryptDecrypt, TestKeyGeneration, TestKeyEncoding. All use real crypto — no mocks.
